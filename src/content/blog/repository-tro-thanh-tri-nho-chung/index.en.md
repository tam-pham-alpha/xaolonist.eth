Hey, it's him again.

In the past, whenever he wanted to ask ChatGPT about a project, he had to carry fragments of code out of GitHub and place them into the conversation. The AI saw only what he had time to explain, like a builder asked to repair a house after being shown a few photographs from outside

Connecting ChatGPT directly to GitHub changes that. It can see not only the code, but also the shape of the project, unfinished pull requests, unresolved issues, and traces of old decisions. The conversation no longer stands outside the product. It begins inside the product's actual memory

The biggest change is not that AI can write code faster. It is that the distance between an idea and a real change is becoming shorter. He can discuss a feature with ChatGPT, let it examine whether the idea belongs in the current system, then hand the defined work to Codex to build and verify

ChatGPT keeps the story, GitHub keeps the state of the product, and Codex turns decisions into code that can run. When these three pieces connect, a repository is no longer merely a place where code is stored. It becomes a shared memory between humans and AI, where even a passing thought may find its way into a real product
