# Oracle → The Way Rename

**Date:** 2026-07-25  
**Status:** Implemented

## Decision

Rename realm **Oracle** (`🔮`) to **The Way** (`☯️`).

Oracle leaned toward prediction and cognition expansion. Recent writing shifts toward inner cultivation: tu tâm, nhân quả, tỉnh thức, năng lượng, vận mệnh. **The Way** (Đạo) fits better — philosophical, short, not tied to one religion.

## New realm definition

| Field | Value |
|---|---|
| Slug | `the-way` |
| Emoji | ☯️ |
| Name | The Way |
| Accent | `#8f9688` (jade/sage) |
| Arc | Awaken (between Accumulate and Transcend) |

## Migration

- `category: "oracle"` → `category: "the-way"` (all posts)
- `/oracle` → `/the-way` (301)
- `/dvvv` → `/the-way` (301, was `/oracle`)
